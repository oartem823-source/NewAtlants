# Информационная система «Расчёт бетона» для ООО «Новые Атланты»

**Разработчик:** Хабиров Артём  Ринатович
**Группа:** ИСП-3323  
**Предприятие:** ООО «Новые Атланты» (поставка бетона)

---

## Описание проекта

Информационная система предназначена для учёта поставок бетона на строительные объекты. Система позволяет фиксировать объёмы поставок, отслеживать марки бетона, суммы и статус оплаты.

---

## Функционал системы

| Функция | Описание |
|---------|----------|
| **Просмотр поставок** | Вывод всех поставок с деталями: стройка, марка бетона, объём, дата, сумма, статус оплаты |
| **Добавление поставки** | Выбор стройки, марки бетона, указание объёма и даты поставки. Сумма рассчитывается автоматически |
| **Удаление поставки** | Удаление выбранной поставки из базы данных |
| **Итоги по стройкам** | Сводка по каждой стройке: общий объём, общая сумма, оплаченная сумма |

## Структура базы данных

База данных `NewAtlants_DB` содержит 4 таблицы:

| Таблица | Назначение |
|---------|------------|
| **Поставщики** | Список поставщиков бетона (название, город, телефон) |
| **МаркиБетона** | Справочник марок бетона (наименование, цена за куб) |
| **Стройки** | Список строительных объектов (адрес, поставщик, дата начала) |
| **ПоставкиБетона** | Записи о поставках (стройка, марка, объём, дата, сумма, оплачено) |

**Связи между таблицами:**
- `Стройки.ПоставщикКод` → `Поставщики.Код`
- `ПоставкиБетона.СтройкаКод` → `Стройки.Код`
- `ПоставкиБетона.МаркаКод` → `МаркиБетона.Код`

## Пример работы программы

1. Запуск программы → главное меню с командами 1-4
2. Выбор **«Показать все поставки»** → отображается таблица со всеми поставками
3. Выбор **«Добавить поставку»** → ввод данных (стройка, марка, объём, дата) → автоматический расчёт суммы
4. Выбор **«Удалить поставку»** → выбор из списка и подтверждение
5. Выбор **«Итоги по стройкам»** → сводка по каждой стройке
